# 📦 Keenetic Audio Player v2.0 - Полный пакет

## 🎯 Описание проекта

**Keenetic Audio Player v2.0** - это профессиональный веб-приложение для воспроизведения аудио файлов на роутерах Keenetic и Linux системах.

### ✨ Основные возможности

- 🎧 Воспроизведение MP3, WAV, FLAC, M4A
- 📤 Загрузка файлов через веб-интерфейс (drag-drop)
- 📱 Полностью адаптивный дизайн
- 🎵 Управление плейлистом
- 📊 REST API для интеграции
- 🔄 Автосохранение конфигурации
- 🖥️ Красивый современный интерфейс

## 🚀 Быстрый старт (5 минут)

### Шаг 1: Подготовка

```bash
# Скачайте все файлы в одну папку
mkdir audio-player
cd audio-player
# Скопируйте сюда все файлы проекта
```

### Шаг 2: Установка

```bash
# Дайте права на исполнение
chmod +x install.sh

# Запустите инсталлятор
./install.sh
```

### Шаг 3: Следуйте инструкциям

```
Инсталлятор спросит:
1. Архитектуру (ARM7 для большинства Keenetic)
2. Путь установки (по умолчанию /opt/audio-player)
3. Способ автозапуска (crontab для Keenetic)
4. Запустить ли сейчас?
```

### Шаг 4: Откройте браузер

```
http://localhost:8080        (если на этом ПК)
http://192.168.1.1:8080      (если на роутере)
```

### Шаг 5: Добавьте музыку

```
1. Перетащите MP3/WAV файлы в зону загрузки
2. Они появятся в плейлисте
3. Нажмите "Играть" для запуска
```

**Готово! 🎉**

## 🎮 Основные команды

### Установка

```bash
./install.sh                    # Интерактивная установка
```

### Управление

```bash
./audio-player.sh start         # Запустить
./audio-player.sh stop          # Остановить
./audio-player.sh restart       # Перезагрузить
./audio-player.sh status        # Статус
./audio-player.sh logs          # Логи
./audio-player.sh logs-follow   # Логи в реальном времени
./audio-player.sh upload file   # Загрузить аудио
./audio-player.sh list-tracks   # Список треков
./audio-player.sh info          # Информация
./audio-player.sh uninstall     # Удалить
```

### Если нет скрипта управления

```bash
# Запуск прямо
/opt/audio-player/audio-player

# Просмотр логов
tail -f /opt/audio-player/logs/audio-player.log

# Systemd (если установлен)
systemctl start audio-player
systemctl status audio-player
```

## 🔌 API для разработчиков

### REST Endpoints

```bash
GET /api/playlist               # Получить список треков
POST /api/add-track             # Загрузить новый трек
GET /api/play?id=track_123      # Воспроизвести трек
GET /api/stop                   # Остановить воспроизведение
GET /api/remove-track?id=...    # Удалить трек
GET /api/update-track?id=...    # Обновить название
```

### Примеры

**JavaScript:**
```javascript
fetch('/api/playlist')
  .then(r => r.json())
  .then(data => console.log(data.items));
```

**Python:**
```python
import requests
r = requests.get('http://localhost:8080/api/playlist')
tracks = r.json()['items']
```

**Bash:**
```bash
curl http://localhost:8080/api/playlist | jq
```

## 🛠️ Для разработчиков

### Архитектура

```
HTTP Server
    ↓
Go приложение (keenetic-audio-player-v2.go)
    ├─ REST API endpoints
    ├─ Веб-интерфейс (встроенный HTML/CSS/JS)
    ├─ Управление файлами
    └─ Взаимодействие с плеером (ffplay/aplay/mpg123)
    ↓
Аудио плеер системы
    ↓
Динамики/Выход
```

### Компоненты

1. **Веб-сервер** - Go `net/http`
2. **Интерфейс** - HTML5, CSS3, Vanilla JS
3. **Хранилище** - JSON файл (playlist.json)
4. **Плеер** - системные утилиты

### Расширение

Чтобы добавить функцию:

1. Добавьте Go handler функцию
2. Зарегистрируйте route
3. Обновите HTML/JS интерфейс
4. Пересоберите приложение

## 📊 Системные требования

### Минимальные

- **ОС:** Linux 2.6+
- **Память:** 256 МБ
- **Место:** 10 МБ + место для файлов
- **Сетевое:** Ethernet или Wi-Fi

### Рекомендуемые

- **ОС:** Linux 4.0+
- **Память:** 512 МБ+
- **Место:** 100+ МБ
- **Сетевое:** Гигабит Ethernet

### Для компиляции

- **Go:** 1.16+
- **Место:** 100 МБ
- **Интернет:** Для загрузки зависимостей
